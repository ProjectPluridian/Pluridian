# Pluridian
- This is an Obsidian notes plugin designed for plural systems (DID, OSDD, etc) to aid in fully mapping the mind(s)/system, (and potentially tracking and other features in the future).
- This project is designed for my own __*personal*__ use __*first*__, but I started it because Simply Plural went down, and with there already not being a lot of resources for systems, I'd like to share it with others. I will eventually have a discord set up for development and features input.
- **DISCLAIMER:** for now i have used, and potentially always will be using, AI to aid me in the development of this.
